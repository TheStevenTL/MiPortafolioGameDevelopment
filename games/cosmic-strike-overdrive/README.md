## 📖 Descripción

**Cosmic Strike: Overdrive** es un *shoot 'em up* espacial construido sobre `<canvas>`. Controlas la nave experimental **Apex Overdrive** a través de 3 sectores hostiles, recolectando snacks saludables para potenciar tu nave y enfrentando jefes temáticos de "comida chatarra".

- **¿De qué trata?** Un viaje por 3 sectores llenos de enemigos, power-ups y jefes finales, con disparo automático y esquive activo.
- **Objetivo del jugador:** Sobrevivir, derrotar a los 3 jefes de sector y conseguir la mayor puntuación posible.
- **Mecánica principal:** Movimiento libre de la nave (teclado o ratón) con disparo automático, recolección de power-ups y combate contra jefes con barra de vida propia.

## 🎮 Controles

| Acción | Control |
|---|---|
| Mover nave | `WASD` / Flechas ↑↓←→ o arrastrar con el `MOUSE` |
| Disparo | Automático |
| Pausar | `P` |

## 🛠️ Tecnologías

- HTML5 Canvas API
- JavaScript vanilla (motor de juego, física simple, IA de enemigos y jefes)
- Web Audio API (efectos de sonido sintetizados de forma procedural)
